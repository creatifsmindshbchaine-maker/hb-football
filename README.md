# HB Football ⚽

HB Football est un jeu de football original inspiré des jeux de football modernes.

## Menu principal
1. ⚽ Mode Match
2. 🎮 Commandes clavier
3. 🤖 IA adverse
4. 🏆 Équipes
5. 👤 Joueurs
6. 📈 Carrière
7. ⏱️ Score et chrono
8. 🗺️ Mini-carte
9. ⏸️ Pause
10. 🎨 Interface originale HB Football

## Prototype
Le projet sera développé progressivement avec une base jouable, des équipes et joueurs originaux, une IA, un système de match, une carrière et une interface propre à HB Football.

HB Football n'utilise pas les logos, joueurs, noms, images ou autres assets propriétaires d'EA Sports/FC.
